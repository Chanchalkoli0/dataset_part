# 📊 Sales Data Analysis Project
## 📌 Project Overview
This project analyzes a simple sales dataset to extract meaningful business insights.  
Using **Python and pandas**, the program calculates total sales, identifies best-selling products, and generates a basic sales analysis report.
---
## 🎯 Objectives
- Load and analyze sales data using pandas
- Handle missing values appropriately
- Calculate key sales metrics
- Identify top-selling products and top revenue regions
- Generate a clear, readable report
